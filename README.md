# 📦 CHSR — Gestion et Suivi des Livraisons

Une application web statique dédiée à la **gestion et au suivi des livraisons**, développée en **HTML/CSS/JavaScript**.

## À propos

**CHSR** est une interface web simple et efficace permettant de gérer et suivre les livraisons en temps réel. Conçue en HTML pur, elle est légère, rapide et accessible depuis n'importe quel navigateur sans installation.

## 🌐 Voir l'application en ligne

👉 [Ouvrir CHSR](https://slahdada.github.io/chsr)

## ✨ Fonctionnalités

- 📋 Gestion des livraisons (ajout, modification, suppression)
- 🔍 Suivi de l'état des livraisons
- 📊 Vue d'ensemble des commandes en cours
- 💾 Interface simple et intuitive

## 📁 Structure du projet

```
chsr/
└── index.html    # Application principale
```

## 🛠️ Technologies utilisées

- **HTML5** — structure de l'application
- **CSS3** — mise en forme et design
- **JavaScript** — logique et interactions
- **GitHub Pages** — hébergement gratuit

## 🚀 Utilisation en local

1. Clone le dépôt :
   ```bash
   git clone https://github.com/slahdada/chsr.git
   ```
2. Ouvre le fichier `index.html` dans ton navigateur

## 📝 Modification

Pour personnaliser l'application, modifie directement le fichier `index.html` avec un éditeur de texte (VS Code, Notepad++, etc.).
